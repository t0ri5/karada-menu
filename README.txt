からだ想い献立 v3 — 毎朝更新付き PWA
更新日: 2026-10-18

公開アプリ: https://t0ri5.github.io/karada-menu/
詳しい使い方・取得状況・開発手順: 同梱の README.md

30日分の朝・昼・夕食案、30種類の夕食レシピ、3店舗のチラシ・店舗リンク、特売メモ、献立との食材マッチング、買い物リストを利用できます。
AndroidのChromeで公開アプリを開き、「アプリをインストール」または「ホーム画面に追加」を選んでください。利用者のGitHubログインは不要です。

GitHub Actionsが毎朝08:00 JSTごろに公開ページを確認し、GitHub Pagesへ更新データを公開します。予約実行は遅れる場合があります。
商品はトクバイの当日テキスト掲載から対象食材を抽出します。チラシの期間確認と、商品名・税込価格の抽出は別の処理です。
画像チラシの商品名・税込価格の読取り（OCR）は未対応です。取得できなかった特売はチラシを確認して手入力できます。
