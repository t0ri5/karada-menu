からだ想い献立 PWA (2026-10-18)

収録: 30日分の朝・昼・夕食案、30種類の夕食レシピ、3店舗の公式チラシ・店舗リンク、価格メモ、特売食材との献立マッチング、買い物リスト、オフライン機能。

注意: スーパーの価格・チラシ内容の自動取得は実装していません。公式サイトへのリンクから確認した情報を手入力できます。価格の比較は入力した記録に限り、外部の価格の最安保証はありません。外部データとの同期なし。

公開手順（簡単）:
1. ZIPを解凍する。
2. Netlify Drop (https://app.netlify.com/drop) にログインして、karada_menu_pwa フォルダをドラッグ&ドロップ。
3. 表示された https://...netlify.app/ のURLをスマートフォンのSafari/Chromeで開く。
4. iPhone: Safari共有→ホーム画面に追加。Android: Chromeメニュー→アプリをインストール。
5. 家族にURLを送ると家族も利用可能。ただし記録データはスマートフォンごとに独立。

Netlifyの表示や料金・利用条件は変更されることがあります。利用前に最新の案内を確認してください。

健康面: 栄養成分の自動計算・医療用食事指導は実装されていません。腎機能などを考慮し医療者に確認してください。

Android修正版v2: PNG 192/512アイコン追加。Netlify DropにZIPそのもの、または展開後のファイルが直接入っているフォルダを投入してください。公開URLの直下でアプリが表示されるか確認してください。既存サイトに再配置した際はChromeのキャッシュ更新が必要な場合があります。
